# Epic Retrospectives

Per BMAD `bmad-retrospective` workflow, after each epic is shipped, a retrospective is written here:

```
implementation-artifacts/retrospectives/
└── retrospective-epic-{num}-{date}.md
```

Each retrospective covers:
- What went well
- What didn't
- Process improvements for next sprint
- Action items with owners

The retrospective is invoked with:

```
/bmad-retrospective --epic {num}
```
