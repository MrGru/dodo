# Story E9.2

**Canonical ID:** `e9.2`
**Status:** done
**Epic:** E9 — Build, Release & Licensing engineering

## Story

**As a** release process **I want** every release to publish a manifest the in-app updater can
read **so that** users are offered updates on every platform dodo ships, never silently skipped.

## Acceptance Criteria

- [x] **AC-1**: `tools/update-manifest` is a standalone crate (`exclude = ["tools/*"]` at the repo
      root, its own `Cargo.lock`, built only by the release workflow via `--manifest-path`) — costs
      the shipped binary zero bytes.
- [x] **AC-2**: The manifest points at macOS's `-app.tar.gz` bundle by exact filename (an installer
      swaps the whole `.app`).
- [x] **AC-3**: Any platform missing from a release fails the whole release — a silently absent
      platform means those users are never offered an update.
- [x] **AC-4**: Publishing is create-or-update, since `gh release create` cannot repair a tag that
      already exists and tags here are immutable.

## Where it lives

- `tools/update-manifest/`, root `Cargo.toml` (`exclude`), `src/updater/`
