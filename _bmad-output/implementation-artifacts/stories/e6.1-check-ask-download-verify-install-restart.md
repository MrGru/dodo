# Story E6.1

**Canonical ID:** `e6.1`
**Status:** done
**Epic:** E6 — In-app Updater

## Story

**As a** user **I want** dodo to notice a new release exists without downloading anything until I
say so **so that** I stay in control of what gets installed and when.

## Acceptance Criteria

- [x] **AC-1**: dodo checks silently at startup.
- [x] **AC-2**: Nothing downloads without an explicit click — structural: `services::pipeline::check`
      is never handed a `Downloader`, so it cannot fetch an archive however it's called.
- [x] **AC-3**: A "Check for updates" button in the sidebar footer triggers the full pipeline
      manually.

## Where it lives

- `src/updater/services/pipeline.rs`, `src/updater/mod.rs`, `src/layout.rs`
