# Story E0.1

**Canonical ID:** `e0.1`
**Status:** done
**Epic:** E0 — Core shell & app lifecycle

## Story

**As a** user launching dodo **I want** a single centered window with a collapsible sidebar to
open **so that** I can immediately reach any tool from one place.

## Acceptance Criteria

- [x] **AC-1**: `main.rs` calls `gpui_component::init` before any module `init` (same ordering
      rule `api_explorer::init`/`docker::init` depend on).
- [x] **AC-2**: A 900x620 window opens centered, mounting `DodoApp` (`src/app.rs`).
- [x] **AC-3**: `Layout` (`src/layout.rs`) renders the sidebar and main pane; selecting a sidebar
      item swaps the main pane via the `View` enum.

## Where it lives

- `src/main.rs`, `src/app.rs`, `src/layout.rs`

## Notes

- See `architecture-decisions.md` for why `main.rs`'s module-init ordering matters.
