# Story E4.5

**Canonical ID:** `e4.5`
**Status:** done
**Epic:** E4 — Docker / Podman module

## Story

**As a** user with the sidebar collapsed to icons **I want** Docker's four pages to still be
reachable **so that** I don't lose access to Images/Volumes/Networks just by collapsing the
sidebar.

## Acceptance Criteria

- [x] **AC-1**: Docker is one flat top-level `SidebarMenuItem`, not a nested group — an
      icon-collapsed sidebar renders no children at all, which made a prior nested-group attempt
      unreachable.
- [x] **AC-2**: Docker's four pages live on its own vertical tab rail (`DockerView::render_rail`)
      inside the Docker view.
- [x] **AC-3**: Exactly one visible page polls, every 5 s (`docker::POLL_INTERVAL`), and
      `set_section_active(false)` stops it the instant the section isn't active.
- [x] **AC-4**: `docker::init` registers this module's key bindings, scoped to the `DockerList` key
      context, called from `main` after `gpui_component::init`.

## Where it lives

- `src/docker/mod.rs`, `src/docker/views` (rail rendering), `src/layout.rs` (`pane_title`)
