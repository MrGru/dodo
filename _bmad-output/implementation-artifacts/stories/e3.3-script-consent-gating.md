# Story E3.3

**Canonical ID:** `e3.3`
**Status:** done
**Epic:** E3 — API Explorer

## Story

**As a** user importing a collection with a script attached **I want** to approve it before it runs
automatically **so that** an imported script can't act on my behalf without my knowledge.

## Acceptance Criteria

- [x] **AC-1**: `RequestSnapshot::script_origin` is set to `Imported` by
      `services/collection_import.rs` and never changed by editing.
- [x] **AC-2**: Editing a script changes its content hash, which re-arms the consent gate.
- [x] **AC-3**: One `ConsentKey` covers both the pre-request and post-response hooks together —
      approving one never silently approves the other.
- [x] **AC-4**: Approvals persist in a `data_dir()` file; `ScriptPolicy` starts each launch at
      "Ask for imported" regardless of the prior session.

## Where it lives

- `src/api_explorer/models/script_consent.rs`, `src/api_explorer/services/consent_store.rs`,
  `src/api_explorer/views/script_consent.rs`

## Notes

- An imported script's provenance is a property of the *request*, not of the text — this is what
  stops laundering an imported script past consent by copy-pasting its text into a "new" one.
