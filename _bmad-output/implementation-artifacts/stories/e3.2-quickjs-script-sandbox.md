# Story E3.2

**Canonical ID:** `e3.2`
**Status:** done
**Epic:** E3 — API Explorer

## Story

**As a** developer writing a pre-request or post-response script **I want** it to run in a bounded
sandbox **so that** a broken or malicious script cannot hang dodo or reach outside its request.

## Acceptance Criteria

- [x] **AC-1**: A positive intrinsic allowlist is used; a fresh QuickJS runtime is created per run.
- [x] **AC-2**: A script cannot exceed a 2 s deadline, 16 MiB heap, or 256 KiB per-value cap.
- [x] **AC-3**: `pm.sendRequest` is denied by not existing, but fails with a message that names it.
- [x] **AC-4**: The `Eval` intrinsic is included — `JS_AddIntrinsicEval` sets `ctx->eval_internal`,
      which `JS_EvalInternal` needs even for dodo's own `ctx.eval`; omitting it breaks dodo, not
      just the script.
- [x] **AC-5**: `pm.test`/`pm.expect` are implemented in the `PRELUDE` JavaScript string, handed
      their two host functions as arguments, not as Rust bindings behind a `__`-prefixed global.

## Where it lives

- `src/api_explorer/services/script/quickjs.rs`

## Notes
