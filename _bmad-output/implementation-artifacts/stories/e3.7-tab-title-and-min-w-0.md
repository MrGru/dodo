# Story E3.7

**Canonical ID:** `e3.7`
**Status:** done
**Epic:** E3 — API Explorer

## Story

**As a** developer with several open request tabs **I want** each tab's title to reflect the
request it holds, and the layout to never push the Send button off-window **so that** the tool
stays usable with many tabs open.

## Acceptance Criteria

- [x] **AC-1**: A tab's auto-derived title is the URL's path (`/api/123`, not the host), with the
      host as fallback for an empty path and raw text for anything unparseable
      (`models/tab_title.rs`).
- [x] **AC-2**: An explicitly named tab still wins over the derived title.
- [x] **AC-3**: Every request/response column carries `min_w_0` — without it, the widest child of
      the widest tab sets the column's width and pushes the Send button off-window.

## Where it lives

- `src/api_explorer/models/tab_title.rs`, `render_request_editor`, `render_response_viewer`

## Notes

- The `min_w_0` bug was invisible until the Scripts tab's sandbox notice made it show up at
  1280px — put one on any new pane rather than trimming the text that exposed it.
