# Story E2.1

**Canonical ID:** `e2.1`
**Status:** done
**Epic:** E2 — Encoder / Decoder

## Story

**As a** developer with an encoded blob **I want** Base64 (standard + URL-safe), URL
percent-encoding, and Hex conversions in both directions **so that** I can inspect or produce
encoded values without leaving the app.

## Acceptance Criteria

- [x] **AC-1**: All three codecs support both encode and decode.
- [x] **AC-2**: Base64 supports both the standard and URL-safe alphabets.
