# Story E1.2

**Canonical ID:** `e1.2`
**Status:** done
**Epic:** E1 — JSON Formatter

## Story

**As a** developer who pasted malformed JSON **I want** to see the parse error inline **so that**
I know exactly what's wrong without a separate dialog.

## Acceptance Criteria

- [x] **AC-1**: An invalid input shows its parse error as an inline diagnostic, at the point it was
      detected.
- [x] **AC-2**: No blank result and no modal dialog is produced for invalid input.
