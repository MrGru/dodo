# Story E4.1

**Canonical ID:** `e4.1`
**Status:** done
**Epic:** E4 — Docker / Podman module

## Story

**As a** user with Docker or Podman running locally **I want** dodo to find the right engine
socket automatically **so that** I don't have to configure anything to see my containers.

## Acceptance Criteria

- [x] **AC-1**: Discovery order is: `DOCKER_HOST` → `/var/run/docker.sock` → macOS `podman
      machine` → bollard's Podman defaults.
- [x] **AC-2**: A dangling `/var/run/docker.sock` symlink (common on a Mac that once ran Docker
      Desktop) is handled rather than silently used.
- [x] **AC-3**: A macOS `podman machine`'s actual per-user socket
      (`$TMPDIR/podman/podman-machine-default-api.sock`) is found — bollard's own
      `connect_with_podman_defaults()` only probes Linux paths and would miss it.
- [x] **AC-4**: An unreachable engine shows an error state with Retry.

## Where it lives

- `src/docker/services/engine.rs`
