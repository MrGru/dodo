# Story E3.5

**Canonical ID:** `e3.5`
**Status:** done
**Epic:** E3 — API Explorer

## Story

**As a** developer with a `curl` command **I want** to paste it into the URL box and have it
rebuild the whole request **so that** I don't have to manually re-enter every header and flag.

## Acceptance Criteria

- [x] **AC-1**: `services/curl.rs` parses a `curl` command; it is pure and heavily table-tested.
- [x] **AC-2**: Two guards keep a keystroke containing the word "curl" from firing: a paste is
      distinguished from a keystroke (`state::request::is_bulk_change`), and the parse must yield a
      URL.
- [x] **AC-3**: A parsed command opens a new tab and restores the field it was pasted into, reusing
      the current tab only when it is untouched, so it never overwrites unsaved work.
- [x] **AC-4**: A round-trip property test (`services/codegen/curl.rs`) generates code, hands it to
      `curl::parse`, and requires both to normalize to the same `NormalizedRequest` (over the wire
      request, not the snapshot).

## Where it lives

- `src/api_explorer/services/curl.rs`, `src/api_explorer/services/codegen/curl.rs`
