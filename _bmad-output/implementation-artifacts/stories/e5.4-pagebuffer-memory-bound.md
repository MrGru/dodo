# Story E5.4

**Canonical ID:** `e5.4`
**Status:** done
**Epic:** E5 — Database Explorer

## Story

**As a** user running a query that returns a huge result **I want** dodo to stay responsive and
tell me honestly that there's more **so that** I don't wait forever or get a silently truncated,
misleading view.

## Acceptance Criteria

- [x] **AC-1**: `PageBuffer` stops the driver when rows, total bytes, or one cell trips the budget.
- [x] **AC-2**: A full page still answers `Continue` — proving there was more, which makes the
      footer's truncation notice trustworthy.
- [x] **AC-3**: No `LIMIT` is ever injected into a statement the user wrote.
- [x] **AC-4**: Export re-runs the displayed statement through a dedicated file-backed sink and
      always exports the full result, never the truncated on-screen page.

## Where it lives

- `src/database/models/page.rs`, `src/database/services/export.rs`
