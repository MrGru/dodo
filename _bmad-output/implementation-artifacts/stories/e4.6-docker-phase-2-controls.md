# Story E4.6

**Canonical ID:** `e4.6`
**Status:** placeholder-by-design (not a defect)
**Epic:** E4 — Docker / Podman module

## Story

**As a** user who needs to exec into a container, create/pull/build an image, see fuller stats, or
mark a favorite **I want** those controls to become real **so that** I don't have to leave dodo for
these less-frequent operations.

## Acceptance Criteria (not yet built — each independent)

- [ ] **AC-1 (Exec/Terminal)**: an interactive shell into a running container, replacing the
      current disabled, tooltipped button (`views/widgets.rs`).
- [ ] **AC-2 (Create/Pull/Build)**: real actions behind the toolbar's currently-disabled labelled
      placeholders (`containers.rs`, `views/images.rs`).
- [ ] **AC-3 (Stats)**: metrics beyond the already-live CPU%.
- [ ] **AC-4 (Favorites)**: persisted pinning, currently absent (a seam only).

## Where it lives (today, as placeholders)

- `src/docker/mod.rs` (documents each cut and its reason), `src/docker/views/widgets.rs`,
  `src/docker/views/containers.rs`, `src/docker/views/images.rs`

## Notes

- Each of these four is independent — none blocks another, and each could be its own smaller
  story if picked up. Read `docker/mod.rs`'s doc comment for exactly what was deferred before
  starting any of them.
