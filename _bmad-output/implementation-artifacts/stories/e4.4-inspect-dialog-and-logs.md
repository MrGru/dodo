# Story E4.4

**Canonical ID:** `e4.4`
**Status:** done
**Epic:** E4 — Docker / Podman module

## Story

**As a** user debugging a container **I want** to inspect its full config and read its logs **so
that** I don't have to drop into a terminal.

## Acceptance Criteria

- [x] **AC-1**: A read-only Inspect dialog covers all four resource types (Containers, Images,
      Volumes, Networks).
- [x] **AC-2**: A container log viewer is available as a second tab in the same dialog.
- [x] **AC-3**: The dialog is a `window.open_dialog` entity — never a hand-rolled page-level scrim —
      so it repaints on its own `cx.notify()` and can `.occlude()` clicks underneath it.

## Where it lives

- `src/docker/views/detail.rs`, `src/docker/models/{inspect,logs}.rs`

## Notes

- `views/detail.rs`'s module doc records why a hand-rolled scrim (`div().absolute().inset_0()` plus
  a no-op `on_mouse_down`) does not actually block clicks in GPUI — read it before building another
  modal surface anywhere in dodo.
