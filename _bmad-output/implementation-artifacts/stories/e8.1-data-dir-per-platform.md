# Story E8.1

**Canonical ID:** `e8.1`
**Status:** done
**Epic:** E8 — Persistence & `data_dir()`

## Story

**As a** user on macOS, Windows, or Linux **I want** dodo's persisted data to live in the right
per-platform location **so that** it matches OS conventions and survives an upgrade.

## Acceptance Criteria

- [x] **AC-1**: `data_dir()` resolves to `~/Library/Application Support/dodo` (macOS),
      `%APPDATA%\dodo` (Windows), or `$XDG_CONFIG_HOME`/`~/.config` (Linux).
- [x] **AC-2**: Platform is classified from `build_info::VERSION_INFO.target`, not `#[cfg]`, so all
      three branches are unit-testable from one host.
- [x] **AC-3**: The macOS path is frozen — changing it would orphan every existing installation's
      saved collections.

## Where it lives

- `src/paths.rs`
