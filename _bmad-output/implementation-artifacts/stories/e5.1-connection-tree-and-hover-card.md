# Story E5.1

**Canonical ID:** `e5.1`
**Status:** done
**Epic:** E5 — Database Explorer

## Story

**As a** user with several database connections **I want** one tree with each connection as a root
**so that** I can browse and open several at once without them interfering.

## Acceptance Criteria

- [x] **AC-1**: `state::tree::Forest` holds one `CatalogTree` per connection; selecting a connection
      clears nothing.
- [x] **AC-2**: `state::tree::RowRef` qualifies every element id by its connection, since two
      servers routinely produce the same node id.
- [x] **AC-3**: Opening a root connects it; per-connection actions are a right-click context menu.
- [x] **AC-4**: The disclosure chevron is dodo's own — `gpui_component`'s tree widget draws none.
- [x] **AC-5**: A connection's hover card cannot render a password —
      `ConnectionProfile::details`/`DetailField` has no `Password` variant, and a test asserts this.

## Where it lives

- `src/database/state/tree.rs`, `src/database/models/connection.rs`
