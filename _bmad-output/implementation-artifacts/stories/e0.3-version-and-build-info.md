# Story E0.3

**Canonical ID:** `e0.3`
**Status:** done
**Epic:** E0 — Core shell & app lifecycle

## Story

**As a** CI job or a user on the command line **I want** `dodo --version`/`--build-info` to print
build metadata and exit **so that** I can confirm a packaged binary runs at all without a display.

## Acceptance Criteria

- [x] **AC-1**: `print_build_metadata_and_exit` in `src/main.rs` handles `--version`/`--build-info`
      before any GPUI initialization.
- [x] **AC-2**: `attach_parent_console` restores standard handles on a release Windows build (a
      GUI-subsystem binary has none by default), so output is actually visible.
- [x] **AC-3**: Build metadata is embedded by `build.rs` into `src/build_info.rs`.

## Where it lives

- `src/main.rs`, `src/build_info.rs`, `build.rs`

## Notes

- This path is how CI proves a packaged binary runs at all on a headless runner — keep it free of
  any GPUI initialization.
