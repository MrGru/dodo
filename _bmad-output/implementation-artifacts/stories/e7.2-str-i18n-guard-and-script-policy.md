# Story E7.2

**Canonical ID:** `e7.2`
**Status:** done
**Epic:** E7 — Theming, Settings & i18n

## Story

**As a** maintainer **I want** every user-facing string to be enforced through translation **so
that** an untranslated literal can never silently reach the screen.

## Acceptance Criteria

- [x] **AC-1**: Every user-facing string routes through `Str`, never a bare literal in view code.
- [x] **AC-2**: Two `cargo test` guards enforce this: no bare literal in view code, no untranslated
      literal reaches the screen.
- [x] **AC-3**: `ScriptPolicy` (governing whether an imported script's hooks auto-run) is a global
      that starts every launch at "Ask for imported," regardless of the prior session's choice.

## Where it lives

- `src/i18n.rs`, `src/i18n_lint.rs`
