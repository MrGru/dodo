# Story E3.1

**Canonical ID:** `e3.1`
**Status:** done
**Epic:** E3 — API Explorer

## Story

**As a** developer sending a request with a script and template variables **I want** a
deterministic pipeline **so that** the order of operations is predictable and testable.

## Acceptance Criteria

- [x] **AC-1**: The send pipeline runs, in order: pre-request script → resolve `{{name}}` →
      `prepare` → `Transport::execute` → post-response script.
- [x] **AC-2**: The pipeline is one blocking function over trait objects, unit-testable with a fake
      transport and a fake script engine, with no `Window`.
- [x] **AC-3**: A script runs *before* substitution (a `pm.variables.set("timestamp", …)` template
      resolves within the same request); `prepare` still runs *last* so a header/URL a script wrote
      goes through dodo's own validation.

## Where it lives

- `src/api_explorer/services/send.rs`, `src/api_explorer/models/interpolate.rs`

## Notes

- `services/send.rs`'s module doc argues both ordering choices; read it before changing hook order.
