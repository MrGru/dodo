# Story E6.2

**Canonical ID:** `e6.2`
**Status:** done
**Epic:** E6 — In-app Updater

## Story

**As a** macOS user installing an update **I want** the swap to be safe even if it fails partway
**so that** dodo never ends up half-replaced.

## Acceptance Criteria

- [x] **AC-1**: The swap is two renames with an explicit rollback, not a single
      `renamex_np(RENAME_SWAP)` call (avoiding a direct `libc` dependency for one call on one
      platform).
- [x] **AC-2**: A half-failed rename is an `Err`; nothing else about installation is.

## Where it lives

- `src/updater/services/installers/swap.rs`
