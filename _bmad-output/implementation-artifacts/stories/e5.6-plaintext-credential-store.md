# Story E5.6

**Canonical ID:** `e5.6`
**Status:** done
**Epic:** E5 — Database Explorer

## Story

**As a** user saving a database connection with a password **I want** to know exactly how it's
stored **so that** I'm never surprised by where my credential lives.

## Acceptance Criteria

- [x] **AC-1**: A password is stored in plain text under `data_dir()`, masked in the UI.
- [x] **AC-2**: A notice about this is never absent from the connection form.
- [x] **AC-3**: No OS keychain integration and no `keyring` dependency exist, on any platform.
- [x] **AC-4**: No `CredentialStore` trait exists — one storage behavior doesn't need one.
- [x] **AC-5**: A store test asserts the password really is in the file, so nobody assumes
      otherwise later.

## Where it lives

- `src/database/models/connection.rs`, `src/database/services/connection_store.rs`
