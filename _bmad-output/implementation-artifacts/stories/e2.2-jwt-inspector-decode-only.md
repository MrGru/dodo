**Status:** done

## Story

**As a** developer with a JWT **I want** it split into header/payload/signature **so that** I can
read its claims without a third-party site.

## Acceptance Criteria

- [x] **AC-1**: A JWT is split into three panes: header, payload, signature.
- [x] **AC-2**: This is decode-only — no signature verification is performed or implied by the UI.
