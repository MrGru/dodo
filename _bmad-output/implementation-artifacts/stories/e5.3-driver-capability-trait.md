# Story E5.3

**Canonical ID:** `e5.3`
**Status:** done
**Epic:** E5 — Database Explorer

## Story

**As a** maintainer adding a second database backend **I want** the object tree and capability set
to be driver-answered questions **so that** a new backend is one file, not a rewrite of the UI.

## Acceptance Criteria

- [x] **AC-1**: A driver answers "the children of this node" — nothing above `services/` knows
      PostgreSQL puts schemas under a database and SQLite does not.
- [x] **AC-2**: The `Driver` capability set (Cancel, Explain) grows only with a shipped control
      that reads it — transactions, column provenance, `LIMIT`/`OFFSET` don't exist because nothing
      reads them yet.
- [x] **AC-3**: A node whose children haven't been fetched still gets a placeholder child, since
      `TreeItem::is_folder` is `children.len() > 0` and a childless node draws no disclosure
      triangle or expand event.

## Where it lives

- `src/database/services/mod.rs`, `src/database/state/tree.rs`
