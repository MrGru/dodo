# Story E5.7

**Canonical ID:** `e5.7`
**Status:** placeholder-by-design (not a defect)
**Epic:** E5 — Database Explorer

## Story

**As a** user who wants to edit data, autocomplete a query, or search across everything I have open
**I want** those features to exist **so that** the Database Explorer covers more of my day-to-day
query workflow.

## Acceptance Criteria (not yet built — each independent, may be split into separate stories)

- [ ] **AC-1**: Object detail/DDL tabs for a selected table/view/etc.
- [ ] **AC-2**: Editing/CRUD on a result grid.
- [ ] **AC-3**: Favorites and pinned queries.
- [ ] **AC-4**: Persisted (cross-restart) query history and tab restore — today's history is
      session-only by design.
- [ ] **AC-5**: SQL autocomplete.
- [ ] **AC-6**: Global search across open connections.
- [ ] **AC-7**: A second backend (MySQL/Redis) via the existing `Driver` trait (see E5.3).
- [ ] **AC-8**: Column sorting on the result grid — currently deliberately absent, not disabled.

## Where it lives (today, as stated cuts)

- `src/database/mod.rs` (states each cut explicitly)

## Notes

- The `Driver` capability set (E5.3) only grows with a shipped control that reads it — any of
  AC-1..AC-8 that needs a new driver capability should extend that trait deliberately, not bypass
  it.
