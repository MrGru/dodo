# Story E0.2

**Canonical ID:** `e0.2`
**Status:** done
**Epic:** E0 — Core shell & app lifecycle

## Story

**As a** user closing dodo's one window **I want** the app to quit **so that** I don't have to
separately quit it from a menu bar or dock icon dodo doesn't provide.

## Acceptance Criteria

- [x] **AC-1**: `QuitMode::LastWindowClosed` is set — GPUI's own check, run *after* the window is
      removed, not a callback that force-quits.
- [x] **AC-2**: A macOS-only `cmd-w` key binding closes the window, needed because dodo installs no
      menu bar for that shortcut to normally hang off.

## Where it lives

- `src/main.rs`

## Notes

- `CLAUDE.md` names this exact mechanism and why the macOS binding is necessary; don't reintroduce
  a callback-based force-quit.
