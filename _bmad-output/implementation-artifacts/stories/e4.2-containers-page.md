## Story

**As a** user managing local containers **I want** a list with status, resource use, and quick
actions **so that** I can operate on containers without a terminal.

## Acceptance Criteria

- [x] **AC-1**: Lists containers with colored status badges, live CPU%, published ports, and
      relative last-started times.
- [x] **AC-2**: Instant search, compose grouping, filters, and bulk actions are available.
- [x] **AC-3**: Per-row Start/Stop/Restart/Delete actions work; Delete confirms first.
