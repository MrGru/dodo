# Story E9.3

**Canonical ID:** `e9.3`
**Status:** done
**Epic:** E9 — Build, Release & Licensing engineering

## Story

**As a** maintainer **I want** the app icon derived from one committed master rather than hand-made
per platform **so that** packaging never depends on the host machine.

## Acceptance Criteria

- [x] **AC-1**: `assets/branding/` holds the original artwork and the 1024 RGBA master.
- [x] **AC-2**: `python3 scripts/generate-icons.py` derives the macOS `.icns`, Windows `.ico`, and
      Linux hicolor PNGs, all committed (packaging must not depend on the host — `iconutil` is
      macOS-only).
- [x] **AC-3**: `assets/{branding,macos,windows,linux}` are kept out of the two `#[include]` filters
      in `src/assets.rs` (which embed only `icons/**/*.svg` and `themes/**/*.json`), so the
      branding artwork costs zero binary bytes.

## Where it lives

- `assets/branding/`, `scripts/generate-icons.py`, `src/assets.rs`, `docs/release.md`
