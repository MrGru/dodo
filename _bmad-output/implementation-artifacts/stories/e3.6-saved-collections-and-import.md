# Story E3.6

**Canonical ID:** `e3.6`
**Status:** done
**Epic:** E3 — API Explorer

## Story

**As a** developer with a set of related requests **I want** to save them as a collection and
import an existing Postman/Insomnia collection **so that** I don't have to rebuild requests I
already have elsewhere.

## Acceptance Criteria

- [x] **AC-1**: Collections persist via `DiskCollectionStore` to `collections.json` and are wired
      to a UI panel (`LeftPanel::Collections`, `views/collections_panel.rs`).
- [x] **AC-2**: `services/collection_import.rs` imports Postman/Insomnia (and similar) collections.
- [x] **AC-3**: An imported request's script provenance is marked `Imported` (see E3.3).

## Where it lives

- `src/api_explorer/services/collection_store.rs`, `src/api_explorer/services/collection_import.rs`,
  `src/api_explorer/views/collections_panel.rs`
