# Story E7.1

**Canonical ID:** `e7.1`
**Status:** done
**Epic:** E7 — Theming, Settings & i18n

## Story

**As a** user changing appearance, font size, border radius, or language **I want** the change to
apply immediately **so that** I don't have to restart dodo to see it.

## Acceptance Criteria

- [x] **AC-1**: Theme JSON is vendored and reaches `ThemeRegistry`.
- [x] **AC-2**: Writing `gpui_component::Theme` applies a theme change live.
- [x] **AC-3**: Font size, border radius, and language switch the same way, with no restart.
- [x] **AC-4**: None of these settings persist across restarts (scoped deliberately — distinct from
      the five files that do, E8.2).

## Where it lives

- `src/settings.rs`
