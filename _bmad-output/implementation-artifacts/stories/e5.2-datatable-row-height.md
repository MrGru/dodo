# Story E5.2

**Canonical ID:** `e5.2`
**Status:** done
**Epic:** E5 — Database Explorer

## Story

**As a** user viewing a query result **I want** the header and body rows sized consistently at any
font size **so that** the grid never clips text.

## Acceptance Criteria

- [x] **AC-1**: `DataTable` has one height knob (`Size::table_row_height`) shared by the header row
      and body rows.
- [x] **AC-2**: Each cell is `overflow_hidden` with the size's own vertical padding removed.
- [x] **AC-3**: Row height and both header lines are expressed as multiples of the base text size,
      checked by unit tests at 14/16/18px — not eyeballed once.

## Where it lives

- `src/database/views/result_grid.rs`
