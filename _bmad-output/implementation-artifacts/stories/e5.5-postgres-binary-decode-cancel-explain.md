# Story E5.5

**Canonical ID:** `e5.5`
**Status:** done
**Epic:** E5 — Database Explorer

## Story

**As a** PostgreSQL user **I want** correct row values, a real Cancel, and Explain **so that** I
can trust the result and control a long-running query.

## Acceptance Criteria

- [x] **AC-1**: Rows arrive as binary and are decoded, not via `simple_query`'s text path (which
      would materialize the whole result, defeating the page budget).
- [x] **AC-2**: `numeric` renders as text, not through `f64` — not rounding is the entire reason a
      column is `numeric`.
- [x] **AC-3**: Undecodable types fall back to UTF-8-as-text (right for an enum) or to bytes; the
      header always carries the server's own `format_type` name.
- [x] **AC-4**: Cancel uses PostgreSQL's protocol `CancelRequest` (or SQLite's interrupt handle for
      that backend), never task dropping.
- [x] **AC-5**: Explain runs PostgreSQL's own `EXPLAIN`.
- [x] **AC-6**: The `live` test module skips itself unless `DODO_PG_TEST_HOST` is set.
