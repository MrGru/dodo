# Course Corrections

For significant mid-sprint changes (BMAD `bmad-correct-course` workflow):

```
implementation-artifacts/course-corrections/
└── sprint-change-proposal-{date}.md
```

A proposal MUST be written when:
- Adding/removing a story mid-sprint
- Re-sequencing dependencies
- Discovering a missing constraint
- Major scope expansion

A proposal goes through PASS/CONCERNS/FAIL decision before adoption.
