# Diagram rotation, grouping and alignment plan

This is the working record for the Diagram tool's next three slices. A checked row means the implementation and its named windowless acceptance test are complete; validation and the few behaviours that require a person at the running canvas are recorded separately rather than implied by a green unit suite.

## Phase A — rotation for every element

- [x] **A1 — Put one angle beside every element rectangle.** Add the serialized angle to the document node and edge records, measured in radians about the rectangle's centre; the rectangle remains the authority for position and size. Add the next format version and a migration rung that writes zero for every older element. Files: `models/document.rs`, `models/serialization.rs`, `runtime/nodes.rs`, `runtime/edges.rs`, `runtime/world.rs`. Acceptance: old version fixtures migrate to zero; nodes, connectors and graph edges preserve a non-zero angle through document round-trip and world round-trip.
- [x] **A2 — Make rotated geometry authoritative below rendering.** Add the small geometry operations for rotating a point, rotating a rectangle's corners and computing their axis-aligned bound. Narrow-phase hit testing rotates the pointer by the negative angle into local space; connector and edge distance tests use their rotated geometry. Feed rotated axis-aligned bounds to `SpatialIndex` while keeping its cells axis-aligned. Files: `geometry/`, `runtime/hit.rs`, `runtime/world.rs`, `spatial/mod.rs`. Acceptance: a point in the rotated body's local box hits, an empty corner of its unrotated box does not, and a rotated corner remains discoverable by a viewport/index query.
- [x] **A3 — Carry the angle through both render halves and all three label renderers.** Read the render budgets before changing paint planning. Add angle to the snapshot and paint primitives/cache identity as needed; rotate canvas outlines, text placement and image/rich-node elements around the same centre, and rotate the inline editor by the same value. Files: `budgets.rs`, `render/plan.rs`, `render/snapshot.rs`, `render/cache.rs`, `render/scene.rs`, `render/shapes.rs`, `views/nodes.rs`, `views/images.rs`, `views/flow.rs`. Acceptance: the frame handed to the painter contains rotated body and label geometry in Clean and Sketch styles, and source/windowless contracts show rich nodes, images and the inline editor consume the same angle.
- [x] **A4 — Add the invertible edit.** Add `RotateElements`, apply it only through `FlowEditor`, return the negative rotation as its inverse, and merge adjacent rotations over the same members so a drag consumes one history entry. Files: `commands/edit.rs`, `commands/apply.rs`, `commands/history.rs`, `commands/editor.rs`. Acceptance: rotate/undo/redo restores the painter frame, and many ticks in one drag produce one undo step.
- [x] **A5 — Add the rotation gesture.** Add a rotation grip and pointer target, carry the gesture in the interaction state machine, compute its delta around the selection centre, and snap to 15-degree increments while Shift is held. Add the platform rotation cursor in the view without introducing a second interaction state. Files: `render/snapshot.rs`, `runtime/hit.rs`, `runtime/world.rs`, `interaction/state.rs`, `commands/gesture.rs`, `views/nodes.rs`, `views/flow.rs`. Acceptance: the pure state machine raises rotate commands, Shift snaps at the boundary values, and the real gesture is one undo step.
- [x] **A6 — Record and land the slice.** Add the rotation section to `crates/dodo-flow/src/lib.rs`, run the full locked validation gates, and commit Phase A independently. Acceptance: formatting, clippy and tests are green at the Phase A commit.

## Phase B — real nested groups

- [x] **B1 — Resolve the hierarchy and derive group bounds.** Use `NodeCold::parent` as the sole relationship. Add children, descendants and ancestors queries; validate parent ids while loading; derive every group rectangle from the union of its direct members' rotated bounds and propagate changed bounds through ancestors. Nothing writes a group rectangle directly. Files: `models/document.rs`, `runtime/nodes.rs`, `runtime/world.rs`, `spatial/mod.rs`. Acceptance: nested child/ancestor queries are stable, derived bounds include rotated corners, moving a descendant updates every ancestor's spatial entry, and malformed parent cycles/targets are refused or detached deterministically.
- [x] **B2 — Add Group/Ungroup as inverse edits.** Group reparents the selected outermost elements under one new `ElementKind::Group`; grouping an existing group nests it. Ungroup peels exactly one level and preserves child groups. The inverse records enough ids and parent relationships to restore the same hierarchy in one step. Files: `commands/edit.rs`, `commands/apply.rs`, `commands/editor.rs`, `commands/history.rs`. Acceptance: group/undo/redo and ungroup/undo/redo round-trip parent ids, ids and painter order with one history entry per action.
- [x] **B3 — Include internal edges and connectors.** When both endpoint nodes are descendants of the new group, parent the edge/connector with the group; when either endpoint is outside, leave it outside so existing rerouting remains active. Files: `runtime/world.rs`, `commands/editor.rs`, `commands/apply.rs`. Acceptance: the four inside/outside endpoint combinations assign membership correctly, and an external endpoint connector reroutes after its grouped endpoint moves.
- [x] **B4 — Make selection group-aware and support drill-in/out.** Ordinary clicking resolves a member to its outermost group. A grouped selection draws one dashed outer box with corner grips and a rotation grip on a short stalk, and no member outlines; an ungrouped multi-selection draws that same outer chrome plus one thin solid outline per member, matching the captain's Excalidraw references. Double-clicking a selected group enters one level and selects the child under the cursor; double-clicking a leaf then opens the existing label editor. Escape leaves text editing first, otherwise selects the parent one level out. Files: `runtime/hit.rs`, `runtime/world.rs`, `runtime/selection.rs`, `render/snapshot.rs`, `render/scene.rs`, `interaction/state.rs`, `views/nodes.rs`, `views/flow.rs`. Acceptance: nested click, drill and Escape transitions select the specified ids without a window; leaf double-click still raises the text-edit effect; the painter frame has no member selection outlines for a group and one per member for a loose multi-selection.
- [x] **B5 — Transform whole groups.** Moving translates every descendant. Resizing scales each descendant's position and size around the group's derived rectangle but leaves stroke width and font size unchanged. Rotating rotates each descendant's centre around the group centre and adds the delta to its own angle. Files: `geometry/`, `commands/editor.rs`, `commands/apply.rs`, `runtime/world.rs`. Acceptance: nested descendants receive each transform once, resize preserves style widths/sizes, connectors retain endpoint order/bindings, and each gesture undoes in one step.
- [x] **B6 — Apply properties by intersection and keep depth contiguous.** A selected group's available property rows are the intersection of all leaf descendants; a restyle applies to every descendant. Grouping makes members contiguous in depth without violating the quad/path/image/rich-element run decisions. Read each depth owner before changing it. Files: `properties.rs`, `commands/editor.rs`, `commands/layers.rs`, `render/scene.rs`, `render/snapshot.rs`. Acceptance: a rectangle-plus-text group has no Background row, restyling reaches both render halves, nested member depths are contiguous, and painter order remains correct across promoted paths and images.
- [x] **B7 — Persist the hierarchy.** Round-trip group elements and all parent relationships; step the format only if an older build would lose document meaning, and otherwise document why the current additive representation is safe. Files: `models/serialization.rs`, serialization fixtures/tests. Acceptance: nested groups and grouped connectors survive save/load with equal derived bounds and painter order.
- [x] **B8 — Record and land the slice.** Add the grouping section to `crates/dodo-flow/src/lib.rs`, run the full locked validation gates, and commit Phase B independently. Acceptance: formatting, clippy and tests are green at the Phase B commit.

## Phase C — Align section and grouping keys

- [x] **C1 — Define alignment as movement arithmetic.** Add six align and two distribute operations over element rectangles. A loose selection uses its selected outermost elements; a selected group uses only its direct children. Distribution preserves the first/last extents and spaces three or more members evenly. Emit one existing move/absolute-position edit rather than a new document delta. Files: `properties.rs`, `commands/editor.rs`. Acceptance: all eight operations produce exact expected positions for uneven sizes, groups align direct children rather than leaves, and undo restores every position in one step.
- [x] **C2 — Add `PanelSection::Align` to both section tables.** Show it for any loose selection of at least two elements and for a selected group, exactly between Layers and Actions. Two subjects show six controls; three or more add the two distribute controls as a third row. Distribution is absent at two rather than muted: count-dependent rows are ordinary contextual behaviour, unlike Sloppiness being disabled by a document setting. Files: `properties.rs`. Acceptance: the independently stated section-table test covers loose two-element, loose three-element, group and single-leaf selection, including the six/eight control counts and row order.
- [x] **C3 — Draw the translated controls and contextual Group action.** Load the i18n and widget recipes before editing the render body. Draw align left/centre/right and top/middle/bottom as two rows of three, adding distribute horizontal/vertical as a third row only for three or more subjects. The Actions row's third button is Group for a loose multi-selection and Ungroup for a selected group; it is not a section of its own. Add every label and tooltip to both catalogues. Files: `views/properties.rs`, `crates/dodo-i18n/src/flow.rs` and its English/Vietnamese catalogues/tests. Acceptance: each control maps to the intended editor operation, the contextual action calls the same editor methods as the keys, and both i18n guards pass.
- [x] **C4 — Bind group and ungroup on every platform.** Add Group/Ungroup `EditAction` variants and total `HostOs` key rows for Cmd/Ctrl+G and Cmd/Ctrl+Shift+G, then bind them through the existing canvas scope. Files: `commands/keys.rs`, `views/keymap.rs`, `views/flow.rs`. Acceptance: key-table tests assert every target OS, no duplicate binding exists, and handlers call the same editor methods as the panel/menu paths.
- [x] **C5 — Record, validate and land the slice.** Add the align-and-keys section and an honest manual-verification list to `crates/dodo-flow/src/lib.rs`; update this document with the commands actually run. Run `cargo fmt --all`, `cargo clippy --all-targets --locked -- -D warnings`, and `cargo test --locked`, then commit Phase C. Acceptance: all gates are green and the branch is clean.
